
# Proyecto APM Inversiones E.I.R.L.

## Descripción
Proyecto integrador de Business Intelligence y Big Data orientado al análisis de registros de asistencia y la generación de información para la toma de decisiones.

## 1. Solución Business Intelligence
La carpeta `1. BI` contiene:
- Scripts SQL para el modelo dimensional y el Data Mart.
- Procedimientos de extracción, transformación y carga (ETL).
- Archivos de Power BI y evidencias del dashboard.
- Pruebas de validación y automatización del ETL.
- Resultados de los experimentos BI.

## 2. Solución Big Data
La carpeta `2. BigData` contiene:
- Notebooks de Apache Spark en Databricks.
- Datos utilizados en el procesamiento.
- Implementación de las capas Bronze y Silver.
- Evidencias de transformaciones y análisis.
- Experimentos de rendimiento y calidad de datos.

## 3. Experimentación
Se documentaron cinco experimentos BI y cinco Big Data.

Los archivos incluyen procedimientos, resultados obtenidos y evidencias de las pruebas realizadas.

## 4. Documentación
La carpeta `4. Documentación` contiene el informe académico actualizado y los documentos complementarios del proyecto.

## 5. Reproducción
### BI
1. Utilizar SQL Server.
2. Revisar los scripts SQL y sus dependencias.
3. Preparar la base de datos de prueba.
4. Ejecutar los procedimientos correspondientes.
5. Abrir el archivo de Power BI y configurar su conexión.

### Big Data
1. Acceder a Databricks.
2. Revisar las instrucciones del README de Databricks.
3. Preparar el dataset del proyecto.
4. Ejecutar los notebooks de ingesta y limpieza.
5. Consultar las tablas Bronze y Silver.
6. Ejecutar los experimentos y contrastar los resultados.

## 6. Consideraciones
Los experimentos de escalabilidad incluyen registros sintéticos para realizar comparaciones.

Los tiempos de ejecución pueden variar según el equipo, los recursos y la configuración utilizada.

Los resultados documentados corresponden a las pruebas realizadas y no representan garantías de rendimiento en otros entornos.
